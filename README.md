# 🛡️ Rakshak Solutions

**Your Shield of Protection** - A premium security solutions company website with stunning visual effects and animations.

![Rakshak Solutions](https://img.shields.io/badge/Status-Live-brightgreen)
![Version](https://img.shields.io/badge/Version-1.0.0-blue)
![License](https://img.shields.io/badge/License-MIT-yellow)

## 🌟 Features

- **Cinematic Hero Section** - Dramatic entrance with animated logo, smoke effects, and particle systems
- **Smooth Scroll Animations** - Reveal animations triggered as you scroll through sections
- **Interactive Particle System** - Connected floating particles with dynamic movement
- **Smoke/Energy Effects** - Blue ethereal smoke effects inspired by the brand identity
- **3D Card Interactions** - Service cards with perspective hover effects
- **Counter Animations** - Animated statistics that count up when visible
- **Responsive Design** - Optimized for all device sizes
- **Modern Aesthetic** - Dark theme with blue and red accent colors matching the brand

## 🏗️ Structure

## 📑 Sections

1. **Home** - Hero section with animated Rakshak logo, tagline, and call-to-action buttons
2. **About Us** - Company story with animated shield display and feature highlights
3. **Services** - Six service cards with hover effects and detailed descriptions
4. **Our Team** - Team member profiles with social links
5. **Contact** - Contact form with company details and emergency hotline

## 🎨 Design System

### Colors
- **Primary Blue**: `#4fc3f7` - Main accent color
- **Deep Red**: `#c62828` - Shield/brand color
- **Dark Background**: `#0a0a0f` - Primary background
- **Secondary Background**: `#0d0d14` - Section backgrounds

### Typography
- **Display**: Orbitron - Futuristic headings
- **Headings**: Bebas Neue - Bold section titles
- **Body**: Rajdhani - Clean readable text

## 🚀 Getting Started

1. Clone or download this repository
2. Open `index.html` in a web browser
3. No build process or dependencies required!

### For Development

```bash
# Navigate to project
cd RakshakSolutions

# Start a local server (Python 3)
python -m http.server 8000

# Or use any static file server
npx serve .
```
